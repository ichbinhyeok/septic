## Design

### Customer-intent refinement

The repair visitor wants to check a reported replacement, the pool visitor wants layout evidence before choosing a project location, and the final-record visitor wants to understand whether installation status answers the completion question. Heroes now lead with these questions, a short service explanation and a purpose-specific CTA. SEO titles, canonical paths and privacy boundaries remain unchanged. Reviewed case narratives are summarized as question → record review → useful answer, with source details available in an accessible disclosure. The handoff names the actual output rather than repeating a generic service promise. No new case outcome or field-work guarantee is introduced.

Visual thesis: substantial ivory working papers, forest-green editorial hierarchy, no dashboard cards. Content order: question, illustrative sheet, actual reviewed lesson, practical checks, service handoff and contextual CTA. Interaction: restrained entrance, sticky reading cue, image enlargement and clear keyboard focus; reduced-motion support inherited from `record-work-story.css`.
