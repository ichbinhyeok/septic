# Recovery states

Preview routes:

- `/design-preview/studio/recovery/not-found/`
- `/design-preview/studio/recovery/server/`
- `/design-preview/studio/intake/?mode=review&uploadError=too_large#intake-form`

The recovery family treats an error as a routing moment, not a dead end. The page keeps the property-research atmosphere, explains what happened in one sentence, and offers three genuinely useful next paths without inventing coverage or agency authority.

The public 404/500 template retains its `noindex,nofollow` metadata, response status and intent-based link selection. Form errors stay inline so typed fields remain available; browser security means file inputs must be reattached.
