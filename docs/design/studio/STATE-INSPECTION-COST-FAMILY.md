# State inspection-cost studio family

Status: implemented and browser-verified. Noindex preview only; not deployed.

## Direction

- Visual thesis: a composed property-diligence journal that treats inspection price as the result of scope, evidence and site access—not as a generic price card.
- Content plan: full-bleed regional hero, engagement definition, ordered checks, records-before-field imagery, scope drivers, delivered-work proof, local variation, preparation, sources, FAQ and inquiry.
- Interaction thesis: restrained hero entrance, expandable state/county evidence, and direct estimator handoffs.
- Every state retains its unique inspection guidance, risks, preparation list, county context, FAQs and official sources.

## Reused image system

- Regional property imagery anchors the state context.
- `buyer-folio-v1.webp` frames the inspection as property diligence.
- `file-dividers-v1.webp` separates recorded history from current condition.
- `calculator-landscape-v2.webp` closes the page with a planning-oriented property image.
